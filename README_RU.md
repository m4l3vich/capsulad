# `capsulad`
Универсальный фреймворк и среда исполнения для приложений для прошитых умных колонок «VK Капсула».
Заменяет собой стоковый `voice-agent` и реализует его основную логику:
- Режим Bluetooth-колонки
- Обучение и распознавание вейкворда (поддерживает несколько вейквордов одновременно, которые могут запускать разных ассистентов!)
- Ассистент Маруся (если вы, зачем-то, хотите её вернуть…)
- Управление сетями Wi-Fi
- Управление громкостью и выключателем микрофона

Помимо этого, `capsulad` это платформа для приложений — можно делать свои приложения в виде:
1. Исполняемых бинарных файлов (есть биндинги для Go и Rust)
2. Программ на Python (через встроенный MicroPython)
3. Программ на JavaScript (через встроенный QuickJS)

Для простоты разработки, всё железо и коммуникация между приложениями абстрагируются и унифицируются. Документация для разработчиков достуна [тут](docs/app_development/README.md).

Не умеете программировать? Ничего страшного, нынче все вайбкодят. Вообще-то и этот проект где-то на 85% навайбкожен. В `capsulad` имеется встроенный MCP-сервер, так что ваш ИИ-агент может самостоятельно делать всё что угодно с вашей колонкой. Просто дайте ему ссылку на этот репозиторий и попросите настроить MCP-сервер `capsulad`, он разберётся.

# Установка

>[!IMPORTANT]
>Пока что поддерживаются только шитые «Капсулы Мини» на Amlogic и Rockchip. Поддержка большой «Капсулы» будет совсем скоро — надеюсь, меньше, чем через неделю после первого релиза `capsulad`.

Вам потребуются:
1. Прошитая «VK Капсула Мини» либо со стоковым софтом, либо на Alpine Linux (он есть только для Amlogic)
	- Чтобы прошить вашу «Капсулу Мини», воспользуйтесь https://github.com/librecapsula/capsula-jb
2. Компьютер (любой)
3. Установщик `capsulad`, который можно скачать на странице [Releases](https://github.com/m4l3vich/capsulad/releases)

Скачайте и запустите установщик `capsulad` и следуйте её инструкциям.

# Наши собственные приложения
В `capsulad` встроено два приложения:
- **Часы** — реализация стоковых часов для 7-сегментного дисплея.
	- Из коробки установлено как контроллер дисплея по умолчанию.
	- Есть секундомер, таймер и будильники, которыми можно пользоваться через веб-интерфейс или через вашего голосового ассистента (кроме Маруси…)
- **Кольцо** — приложение, которое может показывать различные эффекты на светодиодном кольце
	- Из коробки установлено как контроллер светодиодного кольца по умолчанию.
	- Есть различные эффекты, настраиваемая палитра цветов и график включения/выключения (можно использовать как ночник, например)

Еще есть несколько дополнительных приложений, которые можно выбрать для установки при начальной настройке `capsulad`:
## Медиаплееры
- **Ресивер AirPlay 2** — клиент для Apple AirPlay, который позволяет проигрывать аудио на колонке с ваших устройств Apple через Wi-Fi.
- **Интернет-радио** — воспроизводит потоковое MP3-аудио через Интернет. Если вам вдруг захотелось почувствовать себя старым.
## Голосовые ассистенты
- **Маруся** — реализация ассистента со стоковой прошивки
- **Простой Ассистент** — делает вид, что слушает ваши команды, но всегда проигрывает только один единственный WAV-файл в ответ. Файл можно поменять.
- **Клиент Cadence** — клиент для https://git.shino.boo/devilreef/cadence, глубоко настраиваемого голосового агента с ИИ. Его сервер очень сложно развернуть, поэтому вот [простая инструкция](deploy/capsulad-cadence-server/README_RU.md) о том, как это сделать.
- **Клиент OpenCapsula** — клиент для https://github.com/yawaflua/OpenCapsule, известного голосового агента с ИИ для прошитых «VK Капсул».
## Умный дом
- **Интеграция с Home Assistant** — даёт управление «Капсулой» через Home Assistant.
- **Громкоговоритель** — HTTP API для воспроизведения WAV-файлов на колонке. Полезно для оповещений.
# Приколы
- **«Саймон говорит»** — реализация игры Simon Says. Динамик подсвечивает стороны светодиодного кольца желтым/зеленым/красным цветом, издавая звук, а вы должны повторить за ним, нажимая на сенсорную панель с нужных сторон.
- **Саундборд** — вы можете загрузить несколько WAV-файлов и настроить их в приложении. Запустив приложение, при нажатии на середину сенсорной панели, динамик будет издавать настроенный звук. Переключаться между звуками можно, проводя пальцев влево-вправо по сенсорной панели.
